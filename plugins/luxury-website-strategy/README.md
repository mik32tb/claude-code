# Luxury Website Strategy Plugin

Master visual and interaction strategy for building premium, conversion-driven websites for high-ticket businesses.

## What It Does

Claude automatically uses this skill when building luxury or conversion-focused websites. Provides a comprehensive design system covering:

- Dark luxury color palette with strict accent usage rules
- Typography system with responsive scaling
- Five-section page structure (Hero, Qualification, Authority, Proof, CTA)
- Motion and micro-interaction guidelines
- 3D element integration strategy
- Performance and accessibility requirements
- QA scoring checklist

## Usage

```
"Build a landing page for a high-ticket consulting firm"
"Create a premium website for a growth agency"
"Design a conversion-focused page for a luxury service business"
```

Claude will apply the luxury design system — dark graphite backgrounds, glassmorphic elements, restrained motion, and conversion-optimized CTA hierarchy — to produce production-ready code that communicates authority and trust.

## Design Philosophy

- Visual polish amplifies trust — it never competes with the offer
- Minimalism with intent, not emptiness
- Luxury through restraint, not decoration
- Systems over services
- Authority over hype
